# Day 4 — Posts, Pages, Media

# Task 1

## Understanding Posts, Pages, Media

Explored the content structure including Posts, Pages, and Media.

Learned that 

1. Posts are used for dynamic content like blogs, 
2. Pages are used for static content like About or Home, and 
3. Media is used to store images and files.

Understood how these components work together to build and display website content.

Performed actions:
- Created a new post: "My Second Post"
- Created a new page: "About Us"
- Added sample content to both
