# Employee & Client Management Dashboard

## Project Overview

This project is a responsive Admin Dashboard built using AdminLTE and Bootstrap 5.

The dashboard includes:

- Employee Management
- Client Management
- Project Tracking
- Theme Settings
- HTML5 API Implementations
- Responsive UI Components

---

# Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- AdminLTE 4
- JavaScript
- LocalStorage API
- SessionStorage API
- Geolocation API
- Notification API
- Clipboard API

---

## Dashboard Home

- Employee count

- Active sessions

- Search functionality
