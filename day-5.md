# Day 5 — Themes & Plugins

# Task 1

## Understanding Themes and Plugins

Explored how Themes and Plugins work in WordPress.

Themes - control the visual design (layout, colors, UI),
Plugins - add extra features (SEO, forms, security, etc.).

Understood that both can be installed, activated, and customized from the dashboard.

Performed actions:
- Navigated to Appearance → Themes
- Viewed available themes
- Navigated to Plugins → Add New
- Explored available plugins
