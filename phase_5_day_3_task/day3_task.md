# Phase 5 Day 3 - Student Dashboard Application

## Project Overview

This project demonstrates a modular JavaScript-based Student Dashboard Application using ES Modules, session storage, and localStorage for state management.

---

## Folder Structure

- index.html (Public Landing Page)
- login.html (Authentication Page)
- assets/
  - css/
  - js/
    - auth.js
    - storage.js
    - students.js
    - ui.js
    - main.js
  - pages/
    - dashboard.html
    - add-student.html
    - edit-student.html

---

## Features Implemented

### 1. Authentication System

- Login validation using demo credentials
- Session storage for login state
- Protected dashboard routes
- Logout functionality

---

### 2. Modular JavaScript Architecture

- auth.js → Authentication logic
- storage.js → localStorage operations
- students.js → business logic (CRUD)
- ui.js → UI rendering
- main.js → application controller

---

### 3. Student Management (CRUD)

- Add student
- Edit student
- Delete student
- View student list

---

### 4. Web Storage

- localStorage → student data persistence
- sessionStorage → login session tracking

---

### 5. UI Features

- Bootstrap-based responsive UI
- Dashboard table rendering
- Empty state handling
- Navigation between pages

---

## Concepts Practiced

- ES Modules (import/export)
- localStorage
- sessionStorage
- CRUD operations
- DOM manipulation
- Separation of concerns
- Error handling

---

## Outcome

Successfully built a modular frontend application that simulates a real-world student management system with authentication, CRUD operations, and persistent storage.
