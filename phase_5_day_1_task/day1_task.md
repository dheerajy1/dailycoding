# Phase 5 Day 1 Task — API Integration, Fetch API & JSON Response Processing

## Task Objective

Develop a fully dynamic, responsive User Directory Web Application that connects securely to a live REST API, handles data streams using modern asynchronous control patterns, reads structured JSON objects, and dynamically updates the DOM.

## Core Topics Mastered

- Native Fetch API Execution
- JSON Response Parsing & Structuring
- JavaScript Async/Await Architecture
- Asynchronous Component UI States (Loading / Error Handling)
- Zero-Hardcoded Variable Bound CSS Composition

## Tech Stack Applied

- **Structure:** Semantic HTML5 Markup
- **Framework:** Bootstrap v5.3.3 via Content Delivery Network
- **Styling:** Modular Architecture with Isolated Specific CSS Sheets & CSS Custom Variables (`:root`)
- **Logic:** Native Vanilla ECMAScript (ES6+) Asynchronous JavaScript

## Implementation Specifications

1. **Dynamic Content Cards:** Successfully parses user profiles directly from the JSONPlaceholder API endpoint (`/users`).
2. **Mandatory Data Tracking:** Maps and presents the explicit attributes for `Name`, `Email`, `Phone`, and `Company Name` inside the card frame layout.
3. **Responsive Grid Design:** Utilizes mobile-first column wrapping breakpoints (`col-12 col-md-6 col-lg-4`) to accommodate clean rendering across all screen viewports.
4. **Resilient Error Tolerances:** Provides real-time interactive visibility switches for handling native network load sequences (`#loading-state`) and network error responses (`#error-state`).
